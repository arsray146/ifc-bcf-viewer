IFC Units

Dare l'unità di misura giusta alle proprietà numeriche di un IFC. Un IfcReal 600 non dice se sono millimetri o metri: qui lo si decide per regola — assegnando l'unità, convertendo il valore o correggendo quelli inseriti in piedi — e ogni valore toccato viene riletto dal file scritto.

Esito —
—

Nel file cambiano solo le proprietà toccate (valore, tipo di misura, unità) e una riga nell'intestazione, che dice che è già passato di qui: così non lo si converte due volte. Le regole si salvano in un quaderno .json che si riapplica alla prossima emissione. Nessun file lascia il computer.
