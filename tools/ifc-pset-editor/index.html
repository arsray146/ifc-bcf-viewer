Pset Editor

Compilare le proprietà mancanti per condizione, non per elemento. Esce un .ifc con i valori scritti e un quaderno di regole che si riapplica tale e quale alla prossima emissione.

Trascina qui il file .ifc — e, se ne hai già uno, il quaderno .json delle regole nessun upload: la lettura e la scrittura avvengono nel browser · il file originale non viene modificato, se ne scarica una copia
— Nessuna modifica è ancora nel file: si applicano tutte insieme quando esporti.
Se l'elemento è Allora scrivi Tocca Conflitti

Il quaderno è vuoto. Una regola è una condizione, non un elenco: «tutti gli IfcWall esterni e portanti → Pset_WallCommon.FireRating = EI 90». Vale su questo file e su quello che arriverà il mese prossimo.

Fuori regola —

Valori impostati su singoli elementi, senza condizione: restano nel file esportato ma non nel quaderno, quindi alla prossima revisione vanno rifatti. Se sono un motivo ricorrente, conviene trasformarli in regola.

Registro delle modifiche —

Scegli una regola dall'elenco, o creane una nuova. Ogni regola dichiara da sola quanti elementi tocca: il numero si aggiorna mentre la scrivi.

—

Il file esportato non porta nessuna marcatura: niente Pset di provenienza, niente dati che non siano del progetto. La tracciabilità sta fuori — nel quaderno .json e nel registro .csv, che si allegano all'emissione. Nessun file lascia il computer.
